4D-planering som skrivbordsprogram

Installeras per användare i din egen mapp – ingen administratör behövs. Fungerar offline efter första starten.

1. Öppna cmd och kör

powershell -NoProfile -Command "irm https://raw.githubusercontent.com/vfalk-NCC/4D-planering/main/install/install.ps1 | iex"

Alternativ: eget program (Electron)

set PLANERING_MODE=electron && powershell -NoProfile -Command "irm https://raw.githubusercontent.com/vfalk-NCC/4D-planering/main/install/install.ps1 | iex"

Avinstallera

uninstall.cmd (tar bort genvägar och mappen; dina data i GitHub påverkas inte).

Blockerar företagets IT-regler skript eller program: be IT godkänna 4D-planering – installationen går inte runt några säkerhetsfunktioner.
